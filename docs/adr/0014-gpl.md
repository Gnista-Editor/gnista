# 0014. E8 is GPL

Status: accepted · 2026-10-28

## Context

E8's Org packages and parts of its undo are ported closely from GNU Emacs and Org ([ADR 0013](0013-following-org-closely.md)), which are GPLv3 or later. [The licensing notes](../licensing.md) set out what that means and the alternative: a permissive core with the GPL-derived packages kept apart and loaded by URL. Until now the manifest said `UNLICENSED`.

## Options considered

1. **GPLv3 or later for everything.** Matches the code it is ported from, so porting from Emacs and Org can go on as ADR 0013 describes. Rules out a closed App Store build, as the notes explain.
2. **A permissive core with GPL packages.** Keeps a closed App Store build possible, but needs the derived core code rewritten clean first, and every further port kept out of the core.

## Decision

E8 is licensed GPL-3.0-or-later as a whole, for now. `LICENSE` holds the licence and `Cargo.toml` says so. Porting from Emacs and Org stays the way of working.

## Consequences

Nothing has to be rewritten, and new Org features can be ported as before. If a permissive core or an App Store build becomes important, the licensing notes describe the clean-room route; the longer E8 stays GPL, the more code that route has to cover.

## Dependencies introduced

None.
